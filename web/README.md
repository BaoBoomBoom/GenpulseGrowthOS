# Genpulse AI Marketing OS (AMOS)

Three-agent operating system for multi-brand content → growth.

## Local

```bash
cd web
npm install
npm run dev -- --host 127.0.0.1 --port 5190
```

**http://127.0.0.1:5190/**

## Agents

| Route | Agent | Job |
|---|---|---|
| `/scientist` | AI Scientist | Evidence, controversy/risk, content-language, evidence score |
| `/creative` | AI Creative Director | Brand voice, format, brief, multi-platform expression |
| `/growth` | AI Growth Manager | Attribution, anomalies, recommendations, weekly allocation |

## Pipeline

`/knowledge` · `/topics` · `/content` · `/brands`

Data seeded from **Genpulse Growth OS v2.xlsx** (Brand Matrix, Platform Strategy, Growth Loop KPIs, Content Database samples).
